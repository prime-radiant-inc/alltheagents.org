# Tier-2 wave-1 harness brief (for Eden) — 2026-08-21

Eight harnesses, one block each. Everything below traces to dossiers/<slug>.md and standardized/<slug>.md; the master table is master.tsv. "Observable" = we measured it ourselves (GitHub, npm, Homebrew, marketplaces, Discord invite API); "maker-claimed" = the company said it.

## Cursor (Anysphere, now SpaceX)
- What it is: the closed-source Cursor code editor's agent, also shipped as a terminal CLI (`agent`, legacy name `cursor-agent` — the binary Paseo drives over ACP), cloud agents on Cursor-hosted VMs (web, phone, Slack, GitHub, Linear) and a TS/Python SDK; routes to OpenAI, Anthropic, Google, Moonshot and Z.ai models plus Cursor's own Grok/Composer models through Cursor-hosted inference; Hobby free, Pro $20, Pro+ $60, Ultra $200, Teams $40/user.
- Who makes it: Anysphere, Inc. (d/b/a Cursor), San Francisco; SpaceX bought it for $60B in stock, closed 2026-08-14, now under the "SpaceXAI" division; previously Series D $2.3B at $29.3B (Nov 2025). Co-founders Michael Truell and Sualeh Asif are bylined on cursor.com without titles (CEO/CPO per press); no DevRel or partnerships lead named.
- Adoption facts: Homebrew 90-day installs 27.9k (IDE) + 4.6k (CLI) and SDK downloads 493k/week npm + 112k/week PyPI (observable; the CLI itself installs via curl, uncounted); the GitHub "repo" is an issue tracker with 33k stars and no code; Cursor says >$1B annualized revenue and "millions of developers" (2025-11-13), 64-70% of the Fortune 500, 50,000+ enterprises; the $2B/$3B/$4B 2026 revenue figures are press/aggregator only; Terminal-Bench 2.1 #4 (Cursor CLI + Grok 4.5, 79.3%).
- How it plugs in: MCP client; own plugin format plus the open Agent Plugins layout, with a reviewed open-source marketplace (100+) and team marketplaces; subagents, ~20 hook events, Plan and Ask modes; first-party ACP (`agent acp`); SDK; reads CLAUDE.md, .claude/skills and .claude/agents but not Claude Code plugin manifests or marketplaces.
- Maker says special: agents do the end-to-end work while the developer decides; one agent across every surface with local-to-cloud hand-off; model choice including cheaper first-party models; enterprise trust (SOC 2, AIUC-1 certification).
  Also: models to be trained on SpaceX's GPU fleet "at reduced costs"; Cursor Router picks the model per request; "100M+ lines of code daily".
- Things worth an opinion on: (a) a $60B all-stock sale to SpaceX — the harness is now a rocket company's subsidiary; (b) the binary name Paseo calls (`cursor-agent`) is labelled "legacy" by the installer; (c) revenue beyond $1B has no Cursor-authored source and the Fortune 500 share is stated three ways on three pages; (d) census pricing, hooks, claude_code_plugin and release fields were all wrong or null.

## Gemini CLI (Google)
- What it is: Google's open-source (Apache-2.0, TypeScript) terminal agent for Gemini models only, with an ACP server mode, a VS Code companion and a GitHub Action; since 2026-06-18 Google routes free, AI Pro/Ultra and free Code Assist users to its closed-source successor "Antigravity CLI", keeping Gemini CLI for Code Assist Standard/Enterprise licences and paid API keys.
- Who makes it: Google LLC (Alphabet), Mountain View. Named on Google's own posts: Ryan J. Salva (Senior Director, Product Management), Taylor Mullen (Senior Staff Engineer, later Principal Engineer), Dmitry Lyalin (Group Product Manager, transition post). No DevRel lead named.
- Adoption facts: 106.6k GitHub stars, 311k npm downloads/week, 840k Homebrew installs in 365 days (rank 68 of all formulae) — observable; Google said ">1 million developers" within three months of launch (2025-10-08) and "100,000+ stars, 6,000 merged PRs" (2026-05-19), no newer absolute count; Terminal-Bench 2.1: 65.8% (Gemini 3 / 3.1 Pro); the transition announcement drew 298 thumbs-down vs 6 up on GitHub.
- How it plugs in: MCP client (no server mode); "Extensions" bundling MCP servers, commands, hooks, skills and subagents, plus Agent Skills; subagents including remote A2A agents; 11 hook events; plan approval mode; first-party ACP (`gemini --acp`, the original ACP reference implementation); no SDK (headless JSON only). No Claude Code compatibility beyond the cross-tool `.agents/skills` path and a configurable context-file name.
- Maker says special: the industry's largest free allowance (at launch); Gemini models with 1M-token context; Google Search grounding and multimodal input; open source; terminal-first with headless mode and a GitHub Action.
  Also: shares its engine and licence with Gemini Code Assist in VS Code; extensions carry a "playbook" teaching the model to use them.
- Things worth an opinion on: (a) the headline differentiator (the free tier) was withdrawn for consumer tiers on 2026-06-18, yet the README and quota page still advertise it; (b) the successor is closed-source and the open repo now continues "for our enterprise customers"; (c) releases still ship weekly, so "maintained" is technically true while the product is being wound down for individuals; (d) census prose says "MCP client and server" — docs show client only.

## Cline (Cline Bot Inc.)
- What it is: an Apache-2.0 open-source coding agent that began as the "Claude Dev" VS Code extension (July 2024) and now also ships a CLI with ACP mode, a TypeScript SDK ("the same harness"), a Kanban web board for parallel agents, a macOS desktop app and a closed-source JetBrains plugin; bring your own key to a dozen-plus providers or local models, or use hosted Cline credits (100+ models), ClinePass ($9.99/mo open-weight models) or Enterprise; every edit and command needs approval by default, with opt-in auto-approve and "YOLO".
- Who makes it: Cline Bot Inc., San Francisco (per funding press); $32M seed + Series A (2025-07-31); Saoud Rizwan is Founder/CEO (bylined on cline.bot); "Head of AI" Nik Pash appears only in third-party snippets (the cline.bot author page 404s); no CTO, head of product or DevRel named on company pages.
- Adoption facts: 5.05M VS Code installs, 6.07M Open VSX downloads, 684k JetBrains downloads, 66.6k GitHub stars, 74k npm CLI downloads/week, 1,113 commits in 90 days (observable); the homepage says "8.0M+ installs" and "8M+ developers" (counting method unknown — the three marketplace counters sum to 11.8M); GitHub's Octoverse 2025 named it the fastest-growing AI OSS project; maker claims 74.2% on Terminal-Bench (Opus 4.7) but no Cline row exists on the public leaderboard.
- How it plugs in: MCP client with its own one-click MCP Marketplace; skills (including .claude/skills), rules (.clinerules, AGENTS.md, .cursorrules), TypeScript plugins with lifecycle hooks (SDK/CLI/Kanban only per docs), workflows; read-only research subagents everywhere plus Agent Teams on CLI/SDK/Kanban; Plan & Act; first-party ACP (`cline --acp`); can use a Claude Pro/Max subscription as a model provider; no Claude Code plugin/marketplace/CLAUDE.md support.
- Maker says special: "The Open Coding Agent" — open source and auditable; works with every model, no lock-in, no inference markup; human-in-the-loop by default with Plan/Act and checkpoints; one engine behind IDE, CLI, SDK and Kanban.
  Also: client-side and private (no indexing, no training on your data); enterprise SSO/SCIM/RBAC; Salesforce Agentforce "built using Cline's architecture"; Fortune 100 logos.
- Things worth an opinion on: (a) "8M+ developers" equals "8M+ installs" on the same page; (b) "every action requires approval" sits next to YOLO mode, headless `-y` and scheduled agents; (c) plugin docs say plugins are not yet available in the VS Code/JetBrains extensions while a blog post says they are reusable there; (d) "open source" is partial — the JetBrains plugin is closed and the desktop app's source location was not found.

## goose (Block / Agentic AI Foundation)
- What it is: an Apache-2.0 open-source general-purpose agent written in Rust — desktop app (macOS/Linux/Windows), CLI, HTTP/ACP server — running on ~40 API providers, local models, ChatGPT/Copilot logins, or on top of other agents (Claude Code, Codex, Amp, Pi as "ACP providers"); free, no paid tier; default mode is "Completely Autonomous" (edits, deletes, shell and extensions without approval).
- Who makes it: built at Block, Inc. (Oakland; NYSE XYZ) from early 2024, launched 2025-01-28, donated to the Linux Foundation's Agentic AI Foundation on 2025-12-09 ("Founded by Block, stewarded by AAIF"). Named: Dhanji Prasanna (Block CTO), Manik Surtani (Head of Open Source), Bradley Axen (tie-breaking core maintainer), Angie Jones (Head of Developer Relations) plus a named DevRel team of seven — the largest named DevRel bench in this wave. Block cut ~40% of staff on 2026-02-26 citing "the tools we're building".
- Adoption facts: 53.2k GitHub stars (the homepage still says 45,000+), 615 contributors, 870 commits in 90 days, 1.53M GitHub release-asset downloads summed, 6.2k Discord members (observable); Homebrew volume is small; Block's shareholder letters: Builderbot (built on goose) reviewed >90% of production code-change requests and made 15% of changes nearly autonomously, and in June 2026 agentic AI helped write and review "nearly all" production code changes (maker-claimed, Block-internal); no benchmark placement located; no external customers named.
- How it plugs in: MCP client (its built-in extensions are themselves MCP servers); four extension mechanisms — MCP "extensions" (70+), plugin.json plugins (skills + hooks, no marketplace), SKILL.md skills, YAML "recipes"; subagents via the `summon` extension; 12 hook events; `/plan` is a planning conversation, not a read-only lock (that is "Chat Only" mode); ACP in both directions; no language SDK, just the server API. Reads .claude/skills and .claude/agents as legacy-compat; CLAUDE.md only if configured.
- Maker says special: open source and locally run, governed in the open at the Linux Foundation; any model ("betting on a single lab means inheriting its ceiling" — Block's Q2 letter); MCP-extensible; "not just for code".
  Also: recipes as shareable workflows; prompt-injection detection, adversary mode, allowlists; "sandbox mode" named on the homepage but not detailed in the security docs.
- Things worth an opinion on: (a) the default is fully autonomous with no approval prompts and no documented OS sandbox, in a tool pitched at non-developers too; (b) foundation-governed with no published maintainer affiliations — who staffs it day-to-day after Block's layoffs is not stated; (c) Block's "nearly all code" numbers cover Block's whole AI program, not goose alone; (d) it can run Claude Code/Codex/Amp/Pi as its backend — a harness that wraps other harnesses while still owning a loop; (e) docs llms.txt still says "MIT licensed" (it is Apache-2.0).

- Who makes it: Amp Frontier Corporation (also styled "Amp Inc."), San Francisco, spun out of Sourcegraph on 2025-12-02 with 20 named co-founders and "profitable" at spinout; no standalone funding round disclosed; Quinn Slack is co-founder and CEO, Beyang Liu and Thorsten Ball co-founders; the press kit names no people and gives one mailbox (amp-devs@ampcode.com) for press, support and enterprise.

- How it plugs in: MCP client; TypeScript plugins "inspired by Pi" (events, tools, commands, skills, custom agent modes); SKILL.md skills; built-in subagents (Search, Oracle, Librarian, Review, GitHub, Painter) plus custom ones; hooks only as plugin events; NO plan mode; NO first-party ACP — Paseo uses an individual's third-party wrapper (tao12345666333/amp-acp, 86 stars); TS and Python SDKs. ## Cross-dossier notes
- Claude Code compatibility spectrum for this wave (weakest to strongest, per dossiers): Gemini CLI and Kiro (open skills/Agent Plugins standards only, nothing .claude) < Amp, Cline, goose (.claude/skills and/or .claude/agents; AGENTS.md rather than CLAUDE.md) < Cursor (CLAUDE.md + .claude/skills + .claude/agents) < Devin (loads .claude-plugin manifests, imports CLAUDE.md/skills/commands/MCP config) < Factory Droid (documented interoperability with Claude Code plugins incl. a claude-plugins-official example). Combined with tier 1, omp and Droid sit at the top.
- ACP: first-party in Cursor, Gemini CLI, Cline, goose (both directions), Devin (also an ACP host), Kiro and Droid. Amp is the only one with no first-party ACP — Paseo's Amp entry depends on a third-party wrapper maintained by an individual.
- Open source is the minority: Gemini CLI and goose are fully open; Cline is partial (JetBrains plugin closed); Cursor, Amp, Devin, Kiro (except Crew) and Droid are closed binaries. Four of the eight (Cursor, Devin, Kiro, Droid) have a GitHub "repo" that is an issue tracker or release shelf with no code — their star counts are not comparable to real OSS projects.
- Default autonomy splits three ways: no prompts at all by default (Amp; goose "Completely Autonomous"); ask before writes/shell (Cline, Gemini CLI, Devin CLI, Kiro, Cursor CLI for commands); Droid's fresh-install default level is unstated.
- Benchmarks: only Cursor (TB 2.1 #4, 79.3%) and Gemini CLI (65.8%) have rows on the public Terminal-Bench 2.1 board; Cline (74.2%), Droid ("#1" in 2025) and Devin (SWE-1.7 model 81.5%) publish self-run numbers that do not appear there — do not compare the two kinds directly.
- Corporate motion in this wave: Cursor sold to SpaceX (closed 2026-08-14); goose donated to the Linux Foundation's AAIF (2025-12-09); Amp spun out of Sourcegraph (2025-12-02); Devin absorbed Windsurf (2025-07-14); Kiro absorbed Amazon Q Developer CLI (end of support 2027-04-30). Only Cline and Factory are unchanged independents.
- Observable adoption vs maker claims diverge most at Amp (no maker numbers since 2025), Devin CLI (2.3k Homebrew installs vs a $492M company run-rate) and Droid ("hundreds of thousands of developers" vs 11k npm/week).
