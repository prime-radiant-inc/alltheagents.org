# Tier-2 wave-2 harness brief (for Eden) — 2026-08-24

Eight harnesses, one block each. Everything below traces to dossiers/<slug>.md and standardized/<slug>.md; the master table is master.tsv. "Observable" = we measured it ourselves (GitHub, npm, PyPI, Homebrew, marketplaces, Discord invite API); "maker-claimed" = the company said it.

## Junie (JetBrains)
- What it is: JetBrains' closed-source, LLM-agnostic coding agent on two surfaces sharing one engine over ACP — a terminal CLI (headless CI mode, Remote mode for monitoring from a phone, four update channels) and the Junie plugin inside JetBrains IDEs; JetBrains Account credits, a Junie API key, BYOK at zero markup (OpenAI, Anthropic, Google, xAI, OpenRouter, Copilot) or local runtimes; Free 5 credits, AI Pro $8.33/mo, AI Ultimate $25/mo.
- Who makes it: JetBrains s.r.o. (Czech legal entity; 2026 corporate overview says HQ Amsterdam; 2600+ employees, privately held and bootstrapped); Kirill Skrygan CEO since Feb 2024; no Junie-specific product or DevRel lead named anywhere.
- Adoption facts: 31.57M IDE-plugin marketplace downloads (observable, includes auto-updates — not users); 960k CLI release-asset downloads since May 2026 (observable floor; npm is a shim at 1.3k/week); JetBrains says 343K Junie users and 240% YoY paid-AI growth; SWE-Rebench #1 at GA (61.6% resolved, quoted from Nebius by the maker); JetBrains' own survey has Junie at 9% adoption vs Claude Code's 39%.
- How it plugs in: MCP client with an AI "Installation Assistant"; extensions (skills + MCP + subagents + commands + hooks) via marketplaces — and it accepts Claude-format .claude-plugin/marketplace.json marketplaces directly, plus imports .claude/.cursor/.codex skills and agents; subagents (auto-delegation only); hooks (EAP); a strong plan mode (committable plan docs); first-party ACP (`junie --acp`); no SDK.
- Maker says special: any model without lock-in ("Stop switching tools. Start shipping."); powered by the IDE — semantic index, build configs and the real debugger ("most coding agents add log statements. Junie opens the debugger"); plan-first ("plan on a strong model, implement on a cheap one").
  Also: Live Prompting mid-task steering labeled an "Exclusive feature"; SOC 2; migration-in-seconds pitch.
- Things worth an opinion on: (a) hc has two census entries (junie + junie-cli) for one product — merge; (b) the biggest adoption number (31.6M) is plugin downloads with auto-updates, not users; (c) hooks are EAP-only, so "hooks: yes" needs a qualifier; (d) docs and the GA post disagree on what ACP stands for (Client vs Communication).

## Qwen Code (Alibaba / Qwen team)
- What it is: Apache-2.0 open-source terminal agent (TypeScript), a hard fork of Gemini CLI at v0.8.2 that stopped syncing upstream at v0.1; also IDE companions, a desktop app, a `qwen serve` daemon, IM bots (Telegram/WeChat/DingTalk/Feishu), GitHub Actions, Computer Use and TS/Python/Java SDKs; multi-protocol across OpenAI, Anthropic, Gemini and Qwen APIs plus local models; the free hosted-model tier died 2026-04-15 — hosted usage now means the $50/mo Coding Plan Pro, API keys or ModelScope's free quota; default mode asks before every edit and command.
- Who makes it: the Qwen team at Alibaba (GitHub org QwenLM); Eddie Wu is Alibaba Group CEO; no Qwen Code lead is named in any official material, and press (unverified) reports the CLI's head and the Qwen tech lead both left in early 2026.
- Adoption facts: 27.3k stars, 64.5k npm downloads/week (~3.91M cumulative), 333k VS Code companion installs (all observable); 2,787 commits in 90 days — partly the agent committing to itself; no maker-published CLI usage number exists; the "3B+ downloads" quoted near it is the Qwen model family, not the CLI.
- How it plugs in: MCP client; extensions with multi-marketplace ingestion — installs plugins from the Claude Code Marketplace, Gemini Extensions Gallery, Qoder and Agent Plugins v1, auto-converting Claude manifests to its own format; subagent files accept Claude Code frontmatter; fork subagents with shared prompt cache, Agent Teams, Arena; 19 hook events; plan mode; first-party ACP; SDKs. Reads AGENTS.md but QWEN.md is primary — no CLAUDE.md.
- Maker says special: explicit Claude Code parity-plus — "If you know Claude Code, you already know Qwen Code — and then some", a README comparison table vs Claude Code, and a roadmap goal to "catch up with Claude Code"; open source "inside and out" (framework + models); beyond-the-terminal surfaces as checkmarks Claude Code lacks.
  Also: self-developing (its own agent files issues, submits PRs, reviews code).
- Things worth an opinion on: (a) the census "Free / open source" pricing is stale — the free hosted tier is gone; (b) the most openly Claude-Code-benchmarked positioning in the whole census, from a direct competitor's model shop; (c) no harness benchmark exists, only model-card scores; (d) commit/velocity numbers are inflated by the agent's own traffic.

## Kilo Code (Kilo)

- Who makes it: Kilo — $8M seed (Dec 2025, Cota Capital lead); Scott Breitenother (CEO, Brooklyn Data founder) and Sid Sijbrandij (Executive Chair, GitLab co-founder); legal name and HQ unconfirmed (CNBC 403, Businesswire timeout).
- Adoption facts: 1.45M VS Code installs + 3.51M Open VSX downloads + 358k JetBrains, 27k stars, 19.9k npm/week, 15.3k Discord members (observable; contributor/commit counts are inflated by inherited OpenCode history); homepage claims "3M+ Kilo Coders" and "40T+ tokens processed" — definition never given; no external benchmark.
- How it plugs in: MCP client with a marketplace; plugins documented as identical to OpenCode's; Agent Skills incl. remote URLs; reads .claude/skills (behind a compatibility toggle), CLAUDE.md and even imports Claude Code session transcripts; subagents incl. Gas Town agent teams; hooks via the plugin system only; Plan/Ask agents; first-party ACP (`kilo acp`); partial SDK.
- Maker says special: "Code with AI without breaking the bank" — models at cost, no markup, no lock-in, no silent model switching; one platform, many surfaces with orchestrated parallel agents; names Cursor, Copilot, Roo Code, Windsurf and Claude Code in comparison pages.
  Also: transparency/permissions pitch (allow/ask/deny globs, .env guards) beside fully autonomous --auto, Cloud Agents and Gas Town.

- Who makes it: Mistral AI SAS, Paris, 1,000+ people; Series C EUR 1.7B at EUR 11.7B (ASML lead); ~EUR 20B 2026 round reported in talks, unconfirmed; the three founders (Mensch/Lample/Lacroix) are the only named leadership — launch posts are bylined "Mistral AI".
- Adoption facts: PyPI 12.7M downloads/30d, up 3.1x month over month (observable, but installer-script and uv-reinstall inflated — read as velocity, not 12.7M developers); 4.9k stars; 27.4k VS Code installs; no maker CLI usage numbers; the "~5M Vibe users" floating around is the rebranded chat app, not the harness.

## Kimi Code CLI (Moonshot AI)
- What it is: MIT open-source TypeScript terminal agent (single binary, `kimi`), the May-2026 successor to the Python kimi-cli — a repo migration plus rewrite by the same team, with `kimi migrate` carrying config over; also a local web server with REST/WS API, a VS Code extension and first-party ACP whose docs name Paseo explicitly; Kimi models by OAuth subscription or API key plus BYO providers via a models.dev importer; reads run free, edits and shell ask, with YOLO and fully unattended Auto modes.
- Who makes it: Moonshot AI, Beijing; ~$2B raised at $20B (May 2026), >$200M ARR company-wide, Aug 2026 pre-IPO talk at $50B unconfirmed; Yang Zhilin founder/CEO; no other English-named leadership.
- Adoption facts: 11.2k stars on the legacy repo + 7.0k on the new one, 536k VS Code extension installs, 33.9k npm/week on the new CLI while legacy PyPI still does 32.4k/week (all observable); K3 subscription sign-ups paused ~48h after launch for GPU capacity (press); no CLI-specific maker numbers; K3's 88.3 Terminal-Bench 2.0 is a model score, not this harness.
- How it plugs in: MCP client with AI-native /mcp-config (conversational, OAuth, no JSON editing); full plugin system with an Official marketplace plus Curated/Custom tabs and per-install trust levels; Claude Code-style agent files explicitly loadable, cross-tool .agents/skills dirs, and a built-in /import-from-cc-codex command that imports Claude Code and Codex instructions, skills and MCP settings; coder/explore/plan subagents; ~20 hook events (fail-open); plan mode; first-party ACP with a published capability matrix; partial SDK.

## Cross-dossier notes
- Claude Code compatibility spectrum for this wave (weakest to strongest): TRAE CLI and Poolside (nothing .claude, AGENTS.md only) < Mistral Vibe (shared skills standard only) < Kilo Code (skills toggle, CLAUDE.md, transcript import) < Kimi Code and Qwen Code (Claude-style agent files / marketplace plugins via conversion, plus explicit import commands) < Junie (accepts Claude-format marketplaces directly, imports .claude dirs) < Auggie (documented .claude-plugin compatibility, reads CLAUDE.md). Auggie and Junie join omp, Droid and Devin at the top of the census-wide list.
- Pi's gravity: Auggie's v2 harness is a Pi fork; wave-1's Amp calls its plugins "inspired by Pi". Fork chains define this wave — Qwen Code (Gemini CLI), Kilo Code (Roo/Cline then OpenCode), Auggie (Pi); only Junie, Kimi, TRAE, Vibe and pool are original harnesses.
- ACP is now table stakes: all eight ship first-party ACP; pool is bidirectional (client + server) and Kimi/TRAE docs name Paseo explicitly.
- Roster corrections that matter: trae-agent is the wrong census target for Paseo's traecli (two entries needed); junie and junie-cli should merge; augment-code should merge into auggie; kimi-code-cli's "abandoned" flag is wrong.
- Benchmarks: not one of the eight has a row on the public Terminal-Bench 2.1 board. Junie cites SWE-Rebench #1 (third-party, maker-relayed), Poolside and Moonshot publish model scores, Auggie and trae-agent publish self-run or paper numbers. Model scores and self-runs are not leaderboard placements.
- Adoption reality check: the loudest numbers are the least CLI-specific — Junie's 31.6M plugin downloads, TRAE's 6M registered users, Vibe's 12.7M PyPI pulls and Kilo's "3M+ Kilo Coders" all measure something other than harness users. The cleanest signals are npm/Homebrew weeklies (Qwen 64.5k, Kimi 33.9k, Auggie 31.8k, Kilo 19.9k) — and Poolside/TRAE CLI have effectively none.
- Access models split hard: fully open and free to run (Qwen, Kimi, Vibe, Kilo clients) vs subscription-gated closed (Junie, Auggie) vs enterprise-only (TRAE CLI) vs free-for-now with training-on-content (pool).
