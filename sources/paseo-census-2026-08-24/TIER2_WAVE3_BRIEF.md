## Grok Build (xAI / SpaceXAI)
- What it is: xAI's Rust terminal coding agent (binary `grok`, ~845k lines), open-sourced Apache-2.0 on 2026-07-15 — fullscreen mouse TUI, headless mode, first-party ACP (`grok agent stdio`, what Paseo drives); default model grok-4.6 with documented BYO OpenAI-compatible endpoints; bundled with SuperGrok/X Premium+ or API pay-as-you-go; default permission mode is Ask.
- Who makes it: SpaceXAI LLC (ex-X.AI Corp), Palo Alto — a wholly owned SpaceX subsidiary since 2026-02-02 (Nasdaq SPCX; Cursor acquired 2026-08-14). Elon Musk founder; Michael Nicolls President; no product/DevRel names anywhere — the launch and open-source posts have no bylines.
- Adoption facts: 26.0k stars in ~6 weeks of public code (observable); but 36 commits in 90 days all from one sync bot, 0 releases/tags, no npm or Homebrew; xAI has published zero usage numbers; ETR says Grok enterprise usage "stalled". Open-sourcing followed a July 2026 incident: the CLI was found uploading users' entire repos (SSH keys, secrets) to xAI storage.
- How it plugs in: MCP client (also reads Claude Code and Cursor MCP configs); skills/plugins/marketplaces; the strongest Claude Code compatibility claim of any harness — "fully compatible with Claude Code with zero configuration" (marketplaces, plugins, skills, agents, hooks, CLAUDE.md, managed settings, flag aliases); subagents with worktrees; 15 hook events; enforced plan mode; first-party ACP; no SDK.
- Maker says special: plan-first workflow; extensibility in one modal; drop-in Claude Code compatibility; open source as trust ("publishing the code is the most direct way to build toward a robust and reliable harness").
  Also: enterprise fail-closed config pinning, OIDC, ZDR; grok-4.6 "most intelligent and fastest model we've built".
- Things worth an opinion on: (a) census `grok-cli` (superagent-ai) is an unrelated third-party product — Paseo's "Grok" is `grok-build`, the entries must not be conflated; (b) open source without open development: bot-synced, contributions refused, no releases; (c) the upload incident is absent from xAI's own open-source narrative; (d) zero-config Claude Code compatibility from the company that just bought Cursor.

## Hermes Agent (Nous Research)
- What it is: MIT open-source general-purpose autonomous agent (Python) — terminal, messaging gateway (Telegram/Discord/Slack/WhatsApp/Signal/Email), desktop app, API server, cron automations, first-party ACP (`hermes acp`); model-agnostic BYO with an optional Nous Portal subscription ($20-$200/mo per press); default "smart" mode has an auxiliary LLM risk-assess shell commands. Coding is one capability, not the framing.
- Who makes it: Nous Research (US, HQ unpublished; $50M Series A from Paradigm at ~$1B, talks at $1.5B). The company site names no people; founders (Jeffrey Quesnelle CEO, Karan Malhotra, Teknium, Shivani Mitra) are press-named only.
- Adoption facts: the biggest observable footprint in the whole census — 235.6k GitHub stars (TechCrunch corroborated 214k in July), 15.5k commits/3,029 contributors in 90 days, 8.6M Docker pulls, 71.6k PyPI/week (all observable); yet zero maker usage numbers, no customers, no first-party benchmarks (an open issue asks for SWE-bench).
- How it plugs in: MCP both directions (client + `hermes mcp serve`); Python plugin system with a commit-pinned community index and install-time security scanning; SKILL.md skills the agent autonomously creates and patches; subagents with worktree isolation; four hook systems (26 plugin events, blocking); plan is only a bundled skill, not an enforced mode; first-party ACP; reads CLAUDE.md/AGENTS.md but not Claude plugin formats.
- Maker says special: "The Agent That Grows With You" — "the only agent with a built-in learning loop" (creates skills from experience, curates its own memory); runs on a $5 VPS or serverless; lives in your messaging apps; no model lock-in.
  Also: ships `hermes claw migrate` — an official OpenClaw migration path; trajectory-generation tooling for training tool-calling models.
- Things worth an opinion on: (a) 0 to 235k stars in ~6 months of public life — corroborated in magnitude but an extreme curve; (b) a general agent whose Paseo role is "coding agent" — the plan-mode gap and prompt-level-only read-only story matter more in that frame; (c) the "only learning loop" superlative is unadjudicated; (d) npm package maintained by a personal account; census slug must dodge the unrelated `nous` entry.

## Cross-dossier notes
- Claude Code compatibility spectrum (weakest to strongest): MiniMax Code and VT Code (open skills format only, own paths) < Hermes (CLAUDE.md/AGENTS.md context + open skills) < Qoder (field-for-field format clone, zero declared compat) < DeepAgents (reads .claude-plugin and .codex-plugin manifests) < CodeBuddy and Cortex Code (declared plugin-spec compatibility, .claude dirs) < Grok Build ("fully compatible... zero configuration" incl. marketplaces, hooks, managed settings, flag aliases). Wave-3 confirms Claude Code's plugin layout is now the de-facto industry standard — three harnesses declare compatibility, two more clone the format silently.
- ACP is first-party in all eight — the first wave where nothing depends on a third-party wrapper. Grok, CodeBuddy, Qoder, Cortex, MiniMax, Hermes, dcode and VT Code all ship their own ACP server.
- Open source splits 4/4: Grok Build, Hermes, DeepAgents, VT Code open; CodeBuddy (ambiguous license), Qoder, Cortex Code, MiniMax Code closed. Grok's is open-code-closed-development (bot sync, no contributions); CodeBuddy's license is contradictory across its own surfaces.
- China/Asia wave: four of eight (Tencent, Qoder/Alibaba, MiniMax, plus xAI's CN-comparable scale) — three with split CN/international editions running different models at different prices. Census schema has no concept of regional editions; it will need one.
- Adoption evidence quality is the worst of the three waves: Hermes has huge observables but no maker numbers; Cortex has maker numbers but almost no observables; Qoder and CodeBuddy route key figures through IDC-via-press and Baidu Baike; MiniMax and Grok are too new or too silent to measure. Only DeepAgents and VT Code are cleanly measurable, and DeepAgents' headline numbers belong to its framework.
- Census hygiene: this wave surfaced two nonexistent/wrong repos (qoder-cli 404, cortex license from the wrong artifact), two unrelated-project collisions (codebuddy, grok-cli), one SDK/CLI conflation (deep-agents-code), and one triage-out candidate (langchain-js-tools).
- Pi lineage keeps spreading: MiniMax Code's TUI derives from Pi TUI; Amp's plugins are "inspired by Pi" (wave 1); Paseo drives all of them.
