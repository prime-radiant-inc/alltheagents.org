Open-source local visual workspace and session/task manager for coding agents (Codex, Claude Code, OpenCode, Copilot). Visual WYSIWYG collaboration: see agent changes as red/green diffs, approve/edit/annotate directly in markdown, mockups, Mermaid, Excalidraw, CSV, data models, Monaco. Parallel session management (Kanban board, search/resume, link files to sessions) plus task tracking both humans and agents can edit. Mobile companion iOS app. Extension system for custom visual editors. Free desktop app for macOS/Windows/Linux.
