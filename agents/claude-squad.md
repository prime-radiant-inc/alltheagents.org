Terminal app (TUI) that manages multiple AI coding agents in separate isolated git worktrees, letting you run multiple tasks simultaneously in the background via tmux. Auto-accept/yolo mode. Review, commit, checkout, and push changes from a single terminal interface. Agent-agnostic -- works with virtually any CLI-based AI coding assistant (Claude Code, Codex, Gemini, Aider, OpenCode, Amp) through configurable profiles.
