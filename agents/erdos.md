Erdos, built by Lotas (founded by Jorge Guerra and Will Nickols), attacked a workflow gap: data scientists iterate constantly on Jupyter notebooks, yet most AI assistants were built around plain source files and treated notebook structure as an afterthought. Its assistant pane searched, read, and wrote notebooks, Python, R, and Quarto files; pulled documentation from a help pane to ground answers; and ran multiple simultaneous conversations using user-supplied OpenAI/Anthropic keys or a zero-data-retention backend. Around it sat a full IDE — plots history organized by file and time, Python/R environments and consoles, database connections, and remote development over SSH and Docker containers. Version 0.2.5 shipped for macOS and Windows in November 2025 under AGPLv3, but the product page is now a bare contact page, no 2026 captures or downloads exist, and its source repo is gone, indicating the project ended.
