Annotation-first UI pair programming: a browser extension (Chrome + Edge + Firefox) that lets humans visually mark up UI elements/regions for AI agents via in-page annotation and draw mode; local-only MCP bridge with no cloud backend, privacy-preserving; auto-registers onui-local MCP for Claude Code and Codex; shadow DOM isolation for stable styling; multi-format export (compact to forensic) for varying agent context needs; batch annotation via Shift+click. Powered by onLLM.dev.
