Remote background agent orchestrator for coding CLIs in the cloud. Multi-agent support with sandbox isolation per agent. Seamless automatic git workflow (branches, commits, PRs). Local handoff via terry CLI. MCP server for task management. BYO subscriptions/API keys. Integrates with Slack/GitHub via @-mentions. Real-time task status streaming to browser. NOTE: This is a snapshot at time of shutdown (January 16, 2026), provided as-is with no maintenance.
