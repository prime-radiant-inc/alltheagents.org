CodeRider is the agentic coding extension from JiHu GitLab (极狐GitLab), the Chinese GitLab company, aimed at development teams working on gitlab.cn infrastructure. It provides agent-role workflows (architect, developer) with task decomposition and automated debugging, multimodal input that converts UI mockups into frontend code and troubleshoots from screenshots, and a GitLab MCP server connecting the agent to repositories, issues, and merge requests across the lifecycle. The model matrix focuses on Chinese frontier LLMs — MiniMax M2.5, GLM-5, DeepSeek-V3.2, Kimi K2.5 — switchable per task, with configurable work modes, prompts, and third-party models for enterprise customization. Distribution is free through the VS Code Marketplace with JiHu account login, and private/hybrid deployment is available for enterprises; the extension identifier (coderider-kilo) indicates derivation from Kilo Code.
