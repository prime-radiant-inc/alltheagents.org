AI-powered PR review agent where each tool uses a single LLM call for low cost (~30s). Platform-agnostic across 5 git providers (GitHub, GitLab, Bitbucket, Azure DevOps, Gitea). JSON-based customizable prompting. Automatically picks up AGENTS.md repo context and SKILL.md agent skills. PR compression strategy handles PRs of any size.
