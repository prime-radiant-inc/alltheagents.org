Agent-first AI-native desktop shell built entirely from scratch (not a VS Code fork) on Electron + React + Monaco, where the agent is the center of gravity with a transparent Think -> Plan -> Execute -> Observe loop. Uniquely includes an IM bot bridge to control the agent workspace externally via Telegram, Slack, Discord, and Feishu. Four Composer modes: Agent, Plan, Ask, Debug.
