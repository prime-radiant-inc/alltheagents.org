Self-hosted control plane for operating AI agents that sits ABOVE agent runtimes (OpenClaw, Claude Code, Codex, CrewAI, LangGraph, AutoGen, Claude SDK) rather than replacing them. SQLite-backed, runs locally. Single dashboard for task dispatch, agent management, spend tracking, quality review (Aegis gate), memory/skills, scheduling, and governance. Multiple interfaces: Web UI, CLI, built-in MCP server, REST API (OpenAPI), WebSocket, SSE. Alpha software.
