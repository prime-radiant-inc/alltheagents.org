Kodu (originally Claude Coder) embedded an autonomous agent in VS Code for users who wanted to describe an outcome — a dashboard, a website, a server — and watch it get built step by step, including converting mockups and wireframes into working apps. The extension handled multi-step builds, debugging, boilerplate automation, and project scaffolding, with community support through Discord. Releases on the marketplace stopped in spring 2025 and the repository shows no current development, so it functions today as a historically notable early VS Code agent rather than an actively maintained option. It was used by VS Code developers experimenting with app-generation agents in 2024-2025.
