AI-native multi-agent development platform built on Kotlin Multiplatform (JVM, Android, iOS, JS, WASM from a single codebase). Core agents (Document, Coding, CodeReview, ChatDB, Artifact) + 9 specialized SubAgents following 'agent-as-tool' pattern. MCP integration, A2A agent commands, Claude Skill loading, SpecKit integration, AGENTS.md awareness, Tree-sitter code intelligence, artifact generation. Ships as IntelliJ plugin, VS Code extension, CLI, desktop, and web.
