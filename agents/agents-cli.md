Distributed agent factory — dispatches multiple AI coding agents (Claude, Codex, Antigravity, Grok, etc.) across your own machines in parallel on existing subscriptions. Fleet management, cross-agent session search, performance insights, routines/monitors scheduling, browser automation via your real Chrome, menu-bar fleet control, and one-config-syncs-to-all-agents resource management. Note: repo redirects to phnx-labs/agi-cli.
