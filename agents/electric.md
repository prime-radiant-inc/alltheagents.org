Real-time sync engine for Postgres (not a coding agent). Uses 'Shapes' for partial replication, fan-out, and data delivery from Postgres to clients. Core protocol is a low-level HTTP API integrating with CDNs for scalable delivery. CRDT-based sync. Positioned as 'the agent platform built on sync' -- enables apps and AI agents to work with live local data.
