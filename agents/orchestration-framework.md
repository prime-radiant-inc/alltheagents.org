Multi-agent orchestration framework (also called 'Agent Gateway') with native Snowflake services support. Routes requests to appropriate tools (Cortex Search for RAG, Cortex Analyst for Text2SQL, Python for custom operations, SQL for custom pipelines) instead of requiring users to choose between them. Uses LLM Compiler architecture from Berkeley AI Research, supports parallel function calling, Trulens tracing, and runs in SPCS/Snowflake Notebooks with a Streamlit UI demo. Not a coding agent harness.
