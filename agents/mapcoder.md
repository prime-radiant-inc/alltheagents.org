Multi-agent code generation framework for competitive programming using four LLM agents (retrieval, planning, coding, debugging) with an adaptive agent traversal schema that dynamically cascades; achieved SOTA pass@1 on 8 benchmarks (HumanEval 93.9%, MBPP 83.1%, CodeContests 28.5%); accepted at ACL 2024. Repo explicitly states it will no longer be maintained (successor is CodeSIM).
