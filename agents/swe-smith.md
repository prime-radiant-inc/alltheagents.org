Toolkit that turns any GitHub repo into a SWE-gym with unlimited auto-generated task instances. Produced 52k task instances and 250+ Docker environments. Used to train SWE-agent-LM-32B achieving 40.2% pass@1 on SWE-bench Verified (+32%). NeurIPS 2025 D&B Spotlight. Supports both fine-tuning and GRPO-style reinforcement learning. Requires Docker; Ubuntu 22.04 only (no Windows/macOS).
