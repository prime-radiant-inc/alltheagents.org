Local desktop workspace that unifies 26 coding agents (Claude Code, Codex, Cursor, opencode, Aider, GitHub Copilot, Grok, Kimi, Pi, Amp, Auggie, Droid, Crush, Cline, Goose, Qwen, Continue, Devin, Kiro, Kilo Code, Vibe, Muse, Agy, Autohand, Kimchi, Prime Agent) under one supervised workspace. Each task gets its own agent and isolated worktree. A project-aware orchestrator plans and delegates to workers. Live Kanban view derived from real PR/CI/review state. Agent-controllable isolated browsers. Closed feedback loop from idea to merge.
