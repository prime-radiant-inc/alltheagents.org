A specification defining AGENT.md, a standardized vendor-neutral Markdown configuration file that lets codebases communicate project conventions to any agentic coding tool; replaces fragmented config files (.cursorrules, .windsurfrules, CLAUDE.md, etc.) with one universal file any AI coding agent can parse; supports hierarchical files and @-mentions for file references; backward-compatible migration via symlinks so existing tools keep working. Authored by Geoffrey Huntley at Sourcegraph, Inc. Not a software package.
