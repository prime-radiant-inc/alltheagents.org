Firebase Studio (formerly Project IDX) gives developers a full development environment in the browser: a Code OSS workspace with Open VSX extensions, Nix-configurable environments, Android emulators and web previews, and repo import from GitHub, GitLab, Bitbucket, or local disk. Its agentic layer is Gemini in Firebase, which codes, debugs, tests, and refactors across the workspace, and an App Prototyping agent that goes from natural language or a drawing to a running full-stack app with backend, auth, and hosting wired up. Preview URLs support sharing with testers, and publishing targets Firebase App Hosting, Cloud Run, or custom infrastructure. Google has announced sunsetting for March 22, 2027, recommending migration to Google AI Studio or Antigravity, so new adoption carries an end-of-life consideration.
