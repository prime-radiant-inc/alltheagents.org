Deterministic, rule-driven output compactor (JSON rules, not LLM vibes) for terminal-heavy agent workflows. Runs commands, observes output, and returns a smaller payload — reducing transcript waste across 80+ agent/IDE integrations via thin host adapters. Raw output bypass via --raw/--full. Most host integrations install a hook/rule/guidance file (Claude Code, Codex, Cursor).
