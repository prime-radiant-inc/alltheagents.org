LLM-based automated code review assistant listening to GitHub/GitLab Webhook events for PR/MR changes; dual-platform GitHub + GitLab support out of the box; two review modes (detailed line-level JSON-driven and general Markdown summary); built-in web admin panel for runtime config management; Redis-powered dedup and persistence with auto-cleanup on PR/MR close/merge; WeChat Work notification integration; async webhook processing. ~90% of code generated by Aider + Gemini.
