Git-native control plane for coding agents that wraps agents like Claude Code, Codex, Cursor, and Aider in an approved, verifiable repository workflow with bounded authority, approval gates, supervisor-observed proof, verification, and closure. Features Task lifecycle management, Agent Change Records (ACR), local context management, recipes (TDD, security review, docs update), two workflow modes (direct and branch_pr), DCO-compliant multi-author commits, SLSA provenance, and Ed25519-signed recipes. Has an integrations/hermes-agentplane-plugin directory.
