Repo-local symbolic indexing engine turning a checked-out repo into a local SQLite knowledge base of symbols, routes, relations, docs, tests, and context. Provides 21 MCP tools, HTTP route extraction across 10+ frameworks, call graph traversal, token-budgeted context packs, and ROI/token-savings reporting via both CLI and MCP without requiring a hosted index.
