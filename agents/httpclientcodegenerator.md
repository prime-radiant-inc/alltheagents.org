Uses Roslyn source generators to produce HttpClient code on the fly at compile time without writing files to disk. No runtime dependency on third-party libraries. Supports flexible HttpClient injection via fields, properties, or resolver methods. NOTE: This is a .NET code generator, NOT an AI coding agent harness.
