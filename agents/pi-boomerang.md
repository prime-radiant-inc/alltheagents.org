Token-efficient autonomous task execution with automatic context summarization for pi coding agent. Executes tasks autonomously, then replaces raw turn history in future context with an expanded handoff summary (changed files, relevant reads, commands, failures, outcome) — saving tokens while preserving work. Supports chain execution, rethrow/loop execution, prompt templates, anchor mode, and an agent-callable tool.
