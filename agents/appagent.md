LLM-based multimodal agent that operates smartphone apps through a simplified action space mimicking human interactions (tapping/swiping) via ADB — no system back-end access needed. Two-phase approach: exploration (autonomous or human-guided) generates a knowledge base of UI element documentation, then deployment completes user tasks. Published at CHI 2025; successor AppAgentX adds an evolving mechanism.
