Pi Agent Launcher addresses a small but real friction for JetBrains users working with the pi coding agent: leaving the IDE to reach a terminal, then finding the right project directory by hand. The plugin adds a launch action that opens pi in an IDE-embedded terminal, anchored to the current project, so the agent's session sits beside the editor where its changes appear. It performs no orchestration — model configuration, authentication, and tools remain pi's own — and it complements rather than replaces the CLI. Published on the JetBrains Marketplace since May 2026, it targets IntelliJ IDEA, PyCharm, and WebStorm users who have adopted pi and want it a click away rather than in a separate terminal window.
