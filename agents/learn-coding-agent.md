Research and learning repository that reverse-engineers and documents the architecture of Anthropic's Claude Code CLI agent from public sources. Reveals hidden features (undercover mode, model codenames, telemetry, killswitches), 12 progressive harness mechanisms, and an unreleased future roadmap. Documentation available in four languages (EN/JA/KO/ZH). Not a tool itself -- a collection of deep analysis reports.
