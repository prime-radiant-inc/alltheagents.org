Autonomous engineering team runtime where one API call spins up a full team (PM, architect, coders, reviewers, testers) that plans, builds, adapts, and ships production-grade software end-to-end. Factory architecture with three nested adaptive control loops, hardness-aware execution, multi-model per-role assignment, continual learning across issues, agent-scale parallelism via isolated git worktrees, explicit technical-debt tracking, checkpointed resume after crashes, and sub-harness mode for issue-level delegation.
