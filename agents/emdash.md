Open-source desktop app (YC W26) for running multiple AI coding agents in parallel, each isolated in its own Git worktree/branch. Provider-agnostic — bring any CLI agent. Local-first with SQLite storage, remote SSH/SFTP support, issue tracker integrations (Linear, Jira, GitHub, GitLab, Asana), and unified diff review/PR/CI/merge workflow.
