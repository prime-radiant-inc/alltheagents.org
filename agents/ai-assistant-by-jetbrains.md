JetBrains extended its IDE assistant to developers working in VS Code, competing in the editor where it previously had no presence. The extension provides an agentic mode that applies changes across multiple files under developer supervision, context-aware chat with Explore and Improve modes, and code completion powered by Mellum across Java, Kotlin, Python, JavaScript, C#, C++, PHP, Go, Rust, and TypeScript. It ships no language-support features itself, expecting users to pair it with a language extension (ReSharper for VS Code is recommended for C#). Access is free during public preview with a JetBrains account — existing AI subscription holders use their plan, others receive a free EAP license — with paid AI plans scheduled after full release. The preview excludes China and collects telemetry under JetBrains' privacy notice.
