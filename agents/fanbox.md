Local-first, zero-config, zero-runtime-dependency desktop cockpit for coding agents that unifies the entire vibe-coding loop (find files, preview, light edit, command agent, see what changed) into a single window. No cloud, no accounts, no remote — data never leaves your machine. Live dashboard where file cards ripple/glow as the agent writes them, follow mode, session replay timeline, 5 independent reviewer subagents that must score >=90, and three distinct themed skins.
