Agent-architecture books usually stop at diagrams, so this Packt companion repository (by Imran Ahmad, 2026) ships runnable Jupyter notebooks for 30 agent architectures across 17 chapters, from single-tool agents to a five-agent claims pipeline in its chain-of-agents orchestrator chapter. Every chapter includes five pre-executed variants — a MockLLM simulation requiring no key, plus OpenAI GPT-4o, Claude Sonnet 4, Gemini Flash 2.5, and local Ollama (DeepSeek) versions — so readers can compare provider behavior or run everything offline. An errata directory and per-chapter READMEs serve as the documentation hub. Its audience is AI engineers studying agent design patterns and readers of the accompanying book.
