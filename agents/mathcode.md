Mathematical coding agent focused on formal theorem proving in Lean. Atomic Lean tools (LeanGoal, LeanCheck, LeanSearch, LeanVerify) for interactive proof construction with strict verification. Persistent Lean feedback backends (in-process Lean REPL, optional Kimina Lean Server). Theorem Library (/theorem-store) and Axiom Library (/axiomatize). Obsidian Theorem Graph for visualizing dependencies. Agentic Lean (free subgoal decomposition, no fixed planner). Three plugin mechanisms: Skills, Tools, Plugins.
