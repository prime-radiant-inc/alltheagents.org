One of the first agent CLIs (Spring 2023), still actively developed. Provider-agnostic and local-first — runs anywhere a terminal runs (SSH, tmux, headless servers, CI). Full extensibility stack (plugins, skills, lessons, hooks, MCP). Persistent autonomous agents (reference 'Bob' running continuously since late 2024). Multi-agent coordination with file leases and message bus. Self-hostable, guardrails for safe autonomous operation. Desktop app (Tauri) and web UI available.
