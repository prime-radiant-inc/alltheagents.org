Cookie session sync tool for AI agents — continuously syncs Mac's Chrome cookie sessions to a Linux box (or second Mac) where agents run, over Tailscale, so agents wake up already authenticated. Handles the hard parts: macOS Keychain decryption, Chrome App-Bound Encryption on source, live CDP injection into Chrome's in-memory store on Linux sink. Pairing-derived per-peer keys, AES-256-GCM, per-CLI secrets bus for bearer tokens/API keys.
