Gives coding agents a sensorimotor cortex — IDE-like code perception (tree-sitter parsing, symbol-aware edits, semantic search, call graphs) and OS-like environment management (background bash, output compression, PTY sessions, undo stack). Hoists host tools so agents keep calling familiar read/edit/bash but get structured, token-efficient operations. Ships as plugins for OpenCode and Pi harnesses.
