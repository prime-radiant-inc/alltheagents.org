Perplexity-like answer engine returning sources, answers, images, videos, and follow-up questions. Combines web search (Brave/Serper) with LLMs (Groq/OpenAI/Ollama), function calling (maps, shopping, stocks, Spotify), semantic caching via Upstash, rate limiting, AI gateway support for 15+ providers, dynamic UI rendering, and dual deployment (Next.js or Express-only).
