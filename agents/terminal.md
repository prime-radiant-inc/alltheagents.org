Unified AI vibe-coding IDE: native terminal, code editor, and coding agent in one desktop app built 100% in Rust (Tauri). Broker Agent is a one-click autonomous AI dev<->review pair with a mechanical (zero-LLM-cost) broker mediating the full design->build->test->review->merge loop on isolated git worktrees. Keeps all projects and terminals on a single screen, runs multiple AI coding CLIs side by side in real PTYs, with an enforced verify loop (must run tests/build and pass before finishing). Includes built-in Monaco editor, Office file editors, SQLite, Chromium browser with AI toolbar, Kanban, Gantt, and remote access via web terminal.
