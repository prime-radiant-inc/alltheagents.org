Python framework for interacting with LLMs — chat, function calling, structured output, RAG, and agentic chains with tools. Key differentiator is guided sampling via grammars and JSON schema generation, enabling most 7B LLMs (even those not fine-tuned for function calling) to perform structured output and function calling. Supports parallel function calling, RAG with ColBERT reranking, and predefined message formatters for many model families (Mistral, ChatML, Vicuna, Llama 2/3, Phi-3, DeepSeek Coder v2). NOTE: No longer maintained — author recommends using ToolAgents instead.
