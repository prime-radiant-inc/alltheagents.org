Lightweight terminal-first AI coding agent using OpenAI-compatible Chat Completions API. Built-in tools for reading files, applying precise edits, searching code, running shell commands, and delegating work to sub-agents. Multi-provider compatibility, context compression for long conversations, token/cost tracking, dual interactive TUI + one-shot scripting mode, built-in shell command safety blocking, and programmatic API for reuse. Very early stage (5 commits).
