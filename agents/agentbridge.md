JetBrains IDE plugin bridging AI coding agents to IntelliJ platform APIs through 120+ native MCP tools, letting agents call deterministic IntelliJ tools (PSI, VFS, refactoring engine, test runner, debugger) directly instead of relying on LLMs to approximate code intelligence from text. Supports 8 agents with one-click switching and cross-client session resume.
