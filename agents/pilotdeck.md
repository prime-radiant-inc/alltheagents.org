Open-source agent operating system (by Tsinghua THUNLP/ModelBest/OpenBMB) centered on 'WorkSpace' isolation — each project gets isolated files, memory, and skills. Traceable white-box memory (visible, editable, rollbackable with Dream Mode consolidation). Smart routing auto-detects task difficulty and routes to appropriate models (~70% cost savings). Always-on background execution that breaks the ask-answer loop. Native MCP support, open plugin architecture, lifecycle hooks. Consistent across Web/CLI/IM front-ends.
