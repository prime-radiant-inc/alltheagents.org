Full-stack AI-powered SWE agent platform: Next.js dashboard, MDX docs site, terminal web client, and installable CLI coding agent ('supercode' on npm), plus a parallel project fine-tuning its own coding-focused LLMs (Qwen3-8B, GLM-4-9B) via dual-track training (Tinker + Modal/Axolotl). Includes a 'skills' system shared across apps.
