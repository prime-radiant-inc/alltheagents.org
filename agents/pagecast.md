Local-first publishing tool that previews HTML reports, Markdown docs, and static mini apps, then publishes them to shareable Cloudflare Pages URLs from the terminal or coding agents. Context-aware publishing (upserts update same URL in same agent session), edge-level password protection, immutable deploy history, activity analytics, and integrations via MCP, Claude Code plugin, and Codex skill.
