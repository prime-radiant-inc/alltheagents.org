All-in-one hub that launches multiple AI coding agents (Claude Code, Codex CLI, Gemini CLI, Pi, OpenCode, etc.) from a single UI with an API bridge that translates between incompatible provider protocols (OpenAI Responses, Chat Completions, Anthropic Messages, Gemini Generate Content). Enables session continuity across desktop/CLI/web/mobile/IM channels (Feishu, Discord, Slack, Telegram).
