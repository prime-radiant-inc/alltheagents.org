Intelligent development framework for Claude Code that adds project awareness via a Hooks system. Uses Ollama (local LLM) to auto-detect project type/framework, recommend 300+ expert Skills, perform intent analysis, and maintain docs automatically. Replaces Memory MCP with document-driven context injection to avoid context explosion.
