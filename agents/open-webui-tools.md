Modular collection of 20+ tools, function pipes, and filters extending Open WebUI into an AI workstation. Standout is Planner Agent v3 — advanced autonomous agent with agentic planning, parallel subagent execution, MCP integration, visual execution tracking, interactive UI modals, and native Open WebUI integration. Covers research, creative generation (music/image/video), and smart routing (Semantic Router with dynamic vision re-routing).
