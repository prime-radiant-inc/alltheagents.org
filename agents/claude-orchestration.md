Multi-agent workflow orchestration plugin for Claude Code; chain AI agents to automate complex tasks using natural language or declarative .flow syntax. Markdown-based plugin with built-in agents (Explore, Plan, general-purpose), custom agents importable from ~/.claude/agents/, temp agents.
