Fluent builder library for writing C# Source Generators (Roslyn) instead of raw IndentedStringBuilder string concatenation; typed builders work with native Roslyn types (e.g., ITypeSymbol); automatically handles namespace imports, class/enum/record construction, and source file naming (.g.cs); version 2.0 ships as pre-compiled library by default (with opt-in source-link mode). Not an AI agent harness.
