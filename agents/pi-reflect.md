Iterative self-improvement for pi coding agents. Define a target behavior/personality and reflect iterates toward it by reading recent conversations and reference material, comparing actual behavior against the target, and making surgical edits to behavioral markdown files (AGENTS.md, MEMORY.md, SOUL.md). Over time corrections get absorbed as rules, memory accumulates durable facts, personality sharpens. Safety: backups, rejecting suspicious deletions, git auto-commit. Impact metrics: correction rate trend, rule recidivism. Invoked via pi slash commands (/reflect, /reflect-config, /reflect-history, /reflect-stats, /reflect-backfill).
