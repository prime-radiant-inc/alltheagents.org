Programmable TypeScript harness framework for building autonomous agents where the agent IS a function composed of hooks (useModel, useSandbox, useSkill, useTool). Not an SDK -- a programmable harness that gives any model the context and environment needed for autonomous work: durable sessions, secure sandboxes, skills, tools, MCP integration, observability, and multi-channel event ingestion. Deploys to Node.js, Cloudflare Workers, GitHub Actions, GitLab CI/CD, Render, or Daytona. Extensibility via Skills, Tools, and Channels.
