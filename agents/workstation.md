Agentic coding orchestrator that lets you control Claude Code from your phone via Telegram or WhatsApp (through OpenClaw). Voice control (WhisperKit/Apple Speech), multi-session management, smart routing by repo name, live notifications with screenshots, plan approvals from phone, and work reports/checkpoints. Ships as an Electron app plus a Claude Code plugin with skills.
