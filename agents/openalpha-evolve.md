Open-source framework inspired by DeepMind's AlphaEvolve that combines evolutionary algorithms with LLM-driven code generation using diff-based mutations and bug fixes. Sandboxed Docker execution for security, modular multi-agent architecture (PromptDesigner, CodeGenerator, Evaluator, Database, SelectionController, TaskManager), and Gradio web UI for interactive task definition.
