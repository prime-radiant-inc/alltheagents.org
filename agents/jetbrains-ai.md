Deep integration of AI features with code understanding and core IDE workflows. Ecosystem includes AI Assistant (assistive), Junie (autonomous coding agent), and Grazie (writing companion). Supports bring-your-own-key (BYOK) for OpenAI and Anthropic, local models via Ollama/LM Studio, on-premises LLMs via Hugging Face. Agent Client Protocol (ACP) enables third-party agents (Claude, Codex, Gemini CLI, Cursor, GitHub Copilot). Enterprise-ready with on-premises, cloud, and hybrid deployment options.
