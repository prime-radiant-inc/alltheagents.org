The repository implements Project 2 of Berkeley's CS188 AI course: adversarial search agents evaluated by the course autograder inside the Pacman maze simulation, with files like multiAgents.py, ghostAgents.py, and an autograder test suite. The README describes it as a personal sandbox for testing AI algorithms via game simulation. There is no language-model integration, no tool use, and no software-generation of any kind — the name's 'multi-agents' refers to adversarial search agents. It was last touched in mid-2024 and remains a personal WIP.
