Terminal workspace/multiplexer aimed at developers with layouts, floating and stacked panes, multiplayer collaboration, a built-in web-client, and a WebAssembly plugin system (plugins can be written in any language compiling to WASM). Not a coding agent harness; a terminal multiplexer. ~35k stars.
