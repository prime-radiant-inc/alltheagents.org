Opinionated, batteries-included Next.js 14 full-stack template explicitly optimized for AI coding assistants (especially Cursor). Includes agent-helpers folder (tasks, scratchpad, logs), .cursorrules, custom Cursor slash commands (/start, /continue, /review, /document, /refactor), and a task-checklist-driven workflow for AI agents.
