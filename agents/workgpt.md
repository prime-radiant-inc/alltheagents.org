Agent framework (AutoGPT/LangChain-style) that takes a directive and an array of APIs, then converses with AI until the directive is complete. Universal API support via OpenAPI files and OpenPM packages. Smart authentication (pass an authKey, library figures out authorization). Includes Puppeteer-based web crawling and Zod-schema-based structured data extraction. Maintained status unclear from README.
