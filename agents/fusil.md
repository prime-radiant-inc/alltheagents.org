Revived Python fuzzing framework focused on finding crashes in CPython, C-extension modules, the CPython Tier-2 JIT, and OOM error paths. Multi-agent async-message-based fuzzing architecture with adaptive aggressivity driven by per-session scoring. Generates standalone test scripts run as sandboxed child processes. NOTE: This is a fuzzing framework, not a coding agent harness.
