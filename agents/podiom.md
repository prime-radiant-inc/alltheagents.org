Open-source, local-first workspace for Claude Code and OpenAI Codex that provides durable context, sessions, projects, tasks, and scheduling for local LLM agents while the native CLIs do the work. Thin orchestration layer with full audit trails and agent identities. Lead agents can delegate work to other agents and turn outcomes into roadmap tasks.
