Multi-Role AI Agent Runtime orchestrating multiple AI roles through a quality-gated pipeline (Brain -> Miranda -> Pappy -> Benson). Maestro manages a subagent pool (brain, strong_model, cheap_model, reviewer, narrator, planner_deep, debugger, reader, vision). MCP support, SQLite persistence, role routing between cheap and strong models, self-improving distillation loop, and training-data export for fine-tuning — all running locally.
