Whailion AI embeds AI-assisted development directly into JetBrains IDEs with a focus on specialized agents for specific domains such as React Native, Vue, Flutter, Laravel, and DevOps, selected automatically by smart agent routing based on the question. The plugin provides streaming chat and tool execution where the assistant can read, write, and edit files and run commands, with each action gated by user approval, and it integrates with the workspace context. Authentication is OAuth-based against a Whailion account on whailion.com rather than user-supplied API keys. The plugin is new and small: free, around 73 downloads, and not yet marketplace-approved. Its target users are JetBrains IDE developers wanting pre-specialized agents for frameworks like React Native, Vue, Flutter, and Laravel.
