Clean-room Rust reimplementation of Claude Code as a terminal coding agent (TUI pair programmer). Multi-provider routing with no telemetry/tracking. Agent Client Protocol (ACP) support for editor integration (Zed, Neovim, JetBrains). Ultracode mode runs a plan -> delegate -> integrate -> verify multi-agent workflow. Unique features: /share (GitHub Gist sharing), /goal for sustained multi-turn objectives, chat forking, memory consolidation.
