Murmell solves the coordination problem that appears when several AI agents — and the humans supervising them — work on one repository: conflicting writes, invisible progress, and agents that die with a laptop. Its cloud machine hosts each project as a canvas of terminal windows where Claude Code, Codex, Kimi, OpenCode, and other agents run side by side, every participant seeing the same terminals, cursors, and live previews in real time. Conflict prevention is enforced by the machine rather than by prompting: an agent claims a file reservation before editing, other agents queue, colliding writes are snapshotted before landing, and a watcher attributes every write to its author. Deliberately, Murmell does not resell model access — users connect their own agent subscriptions and API keys, and finished code lands in a private GitHub repository the team owns. Solo developers running multiple agents use the entry tier; teams on Pro and Builder plans share canvases with role-based collaborators. The service is hosted-only (no self-hosting), waitlist-gated at launch, and priced from $39 to $149 per month.
