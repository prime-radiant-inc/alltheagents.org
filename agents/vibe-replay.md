Turns AI coding sessions into shareable, interactive self-contained HTML replays — animating every prompt, thought, tool call, and code diff. One command, zero config, offline-ready. Secret redaction built in. Live mode streams a running Claude Code or Codex session in real time. Deep analytics: token burn, cost over time, context window usage, cache hit rates, tool call distribution. Claude Code plugin auto-embeds replay context into PR descriptions. No wrappers/proxies — reads existing session logs after the fact.
