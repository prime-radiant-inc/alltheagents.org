Orchestrates multiple AI coding CLI agents simultaneously in isolated tmux sessions, allowing a supervisor to delegate work to specialist agents in parallel or sequence. Supports 11+ provider CLIs, offers a Web UI, MCP server, plugins, flows/workflows, skills, persistent memory with self-learning, and agent profiles — all while keeping each agent as a full native CLI process with its own authentication.
