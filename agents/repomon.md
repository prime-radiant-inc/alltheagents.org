Mission control for managing a fleet of AI coding agents across many repos x many worktrees x many agents simultaneously. Unlike tools that run parallel agents in one repo, repomon is built for developers juggling 5-15 active projects with a fleet of agents running at once. Durable tmux-backed runtime, desktop app and TUI clients, git explorer, in-app editor, fleet mail between agents, remote access via WebSocket bridge, usage limit tracking. An orchestrator (repomind) spawns and manages worker agents.
