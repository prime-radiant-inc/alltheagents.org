Not a coding tool itself — a curated awesome-list comparison directory of AI coding tools that provide free access to pro-grade models (Claude Opus/Sonnet, GPT-5, Gemini Pro, Qwen3-Coder, etc.). Standardizes the definition of 'pro-grade' using SWE-bench Verified (>=60%) and places all tools side-by-side with actual free-tier limits, making hard-to-compare quotas directly comparable.
