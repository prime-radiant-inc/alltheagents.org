Model-driven SDK taking a minimal-code approach to building agents. Model-agnostic (any model, any cloud; swap backends without code changes). Agent loop traces every decision; hooks intercept any step to log/validate/redirect; guardrails catch mistakes before execution with self-correction via steering handlers. Built-in MCP, streaming, multi-agent patterns, and structured output. Dual Python and TypeScript SDKs.
