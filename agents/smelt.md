Small, fast, Lua-scriptable AI coding agent for the terminal (scriptable like Neovim). Custom terminal renderer (not ratatui). Built-in Vim editor (motions, text objects, registers, undo). Deterministic fuzzing with fixed clock and stubbed I/O for replayable crashes. No config needed. Mode cycle: Normal -> Plan -> Apply -> Yolo.
