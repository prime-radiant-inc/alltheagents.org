AI-driven end-to-end security workflow CLI/SDK: discovers, validates, and auto-patches vulnerabilities, verifies fixes, and opens GitHub PRs. Deep multi-agent scans with --subagents flag. Interactive finding review, scan comparison by root cause, Linear issue publishing. Containerized bulk scans with AppArmor hardening. Pluggable inference providers. Extensibility via scan prompt files and knowledge bases.
