Lightweight CLI tool that lets AI coding agents share, inspect, and control your real, running terminal. A shell proxy (not a tmux-like multiplexer) that lets agents observe and interact with terminals you already have running. Proxies I/O, records context, and exposes agent-friendly commands (hitch/unhitch). Integrates with skills.sh via SKILL.md. Supports macOS and Linux on arm64/x64.
