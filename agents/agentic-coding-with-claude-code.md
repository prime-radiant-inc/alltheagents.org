Code repository for the Packt book 'Agentic Coding with Claude Code, First Edition' by Eden Marco. Not a standalone tool — contains chapter-by-chapter code samples (Ch 01-10) teaching how to use Claude Code as an agentic development platform, covering MCP, plugins, subagents, hooks, plan mode, skills, output styles, and multi-agent orchestration. Includes a progressive project ('HookHub') built across chapters.
