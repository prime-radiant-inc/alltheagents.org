Local-first AI coding agent for desktop, terminal, editor (VS Code, Visual Studio, JetBrains), and CI workflows. Works inside a real local repository (not a detached chat sandbox), keeps the human in control with approval prompts/permissions/profiles, stores reusable commands and team memory in versionable .stemcode/ files, reuses the same agent across desktop/CLI/IDE/CI. Profiles include planning, implementation, review, exploration, and delegated work modes. Includes local voice dictation and automatic AI git commits scoped to changed files.
