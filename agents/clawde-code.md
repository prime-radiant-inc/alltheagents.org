The repository preserves and documents the leaked TypeScript implementation of Claude Code, whose accidental publication through an npm source map became one of the most-disclosed views into a production agent harness: roughly 40 agent tools, 50 slash commands, the IDE bridge, the multi-agent coordinator, and the plugin and skills systems. An accompanying MCP server lets Claude Code itself answer questions about the codebase, turning the archive into a study aid. It is not installable or runnable as an agent, and its census value is architectural reference. The repository has seen no commits since publication and remains up at the owner's discretion.
