Public-Agent-Framwork presents the Auralia Agent Framework, a TypeScript toolkit for building agent workflows with a sandboxed code interpreter, prebuilt and custom agents, pluggable tools, and serialization for pausing and resuming long-running processes. It is tuned for IBM Granite 3.0 and Llama 3.x models with Ollama support, and exposes an OpenAI-compatible Assistants API plus an emitter-based instrumentation system. The repository is a rebranded clone of IBM's Bee agent framework — the feature list, README structure, and legal notice match, with 'Bee' renamed to 'Auralia' throughout. IBM's notice states plainly that the code will not be maintained, and the repository shows two commits, no stars, and no releases since December 2024. It functions as an abandoned mirror of IBM Bee rather than an independently maintained framework.
