Governance and continuity harness around AI coding agents. Provides task traceability, structural gates, session continuity, audit trails, blast-radius foresight, value scoring, and cross-agent coordination. It coordinates agents but does not execute them. Enforces 'nothing gets done without a task' as a hard gate (PreToolUse hooks), three-layer persistent memory, Component Fabric for blast-radius impact analysis, Business Value Points (BVP) scoring, a tiered authority model (human sovereignty / framework authority / agent initiative), and 260+ audit checks. Develops itself under its own governance.
