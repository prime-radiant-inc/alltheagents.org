Open-source AI-powered terminal agent built with Go, Bubble Tea TUI, and Open Agent SDK. Features 78 built-in slash commands, custom Skills system (user-defined sub-agents via SKILL.md files), plugin architecture, pre/post tool use hooks, plan mode, Chinese/IME input support, self-update capability, and compatibility with both CODEANY.md and CLAUDE.md project instruction files.
