Local-first autonomous coding agent (v1.0.0) that plans, edits, runs commands, debugs failures, validates results, and continues until software tasks are finished end-to-end. Local-first: control plane, execution, session history, and checkpoints all stay local. Failure recovery via durable event ledger, checkpoints, and reverts. Demonstrated a 4h 33m autonomous run (16,393 events, 373 tool outcomes) reaching FINISHED with no additional user messages. Real LSP and DAP integrations.
