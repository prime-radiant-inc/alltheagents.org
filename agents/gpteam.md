Open-source multi-agent simulation where autonomous AI agents with individual memories interact, move between locations, perform tasks, and collaborate in parallel toward common goals. Agent memory and reflection are inspired by the Generative Agents paper. Includes a Discord integration for observing agent behavior. A research-style simulation rather than a coding-agent harness.
