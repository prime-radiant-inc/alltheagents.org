Sourcery began as a Python refactoring engine and now operates as an automated review and security layer across the places code changes flow: pull requests on GitHub and GitLab, continuous repo-wide security scans, and real-time feedback inside VS Code and JetBrains IDEs. Its findings are structured so coding agents such as Claude Code can consume them and produce the actual fixes, which is how it participates in agentic workflows without being one. The core engine is MIT-licensed on GitHub while team features run as a commercial service, and enterprise deployments can point at customer LLM endpoints with zero code retention, backed by SOC 2 certification. It suits teams that want review coverage and vulnerability detection across every PR without adding a reviewer bottleneck.
