Open-source, terminal-native coding agent (IDE) keeping you in the terminal. NeoLens built-in local codebase explorer visualizes TypeScript dependency graphs, offers read-only file previews, and replays agent activity timelines (tokens, durations, costs) without sending source to cloud. PLAN mode (read-only investigation) and BUILD mode (implementation). MCP integrations via project-local .neocode/mcp.json (stdio and Streamable HTTP transports). Switchable plan/build agents via /agents command.
