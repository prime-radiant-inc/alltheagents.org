Diff-aware AI code review tool that uses relevant codebase context rather than isolated files. CLI-first design suited for terminal and CI/CD workflows. Runs locally with Ollama for privacy or with cloud LLMs. Configurable review focus (security, performance, style) and can suggest fixes, not just flag issues.
