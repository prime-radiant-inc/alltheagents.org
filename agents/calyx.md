Native macOS terminal (built on Ghostty) for running and supervising multiple coding agents (Claude Code, Codex, OpenCode, Hermes, Grok, pi) in parallel. Provides one approval inbox, live agent status sidebar, persistent sessions, agent-readable command history, inline diff review, IPC between agents, LSP proxy, and browser scripting.
