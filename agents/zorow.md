Zorow (z/OS Open Repository of Workflows) collects workflow definitions for IBM's z/OS Management Facility, the framework mainframe administrators use to run guided, repeatable tasks on z/OS systems: configuring software products, provisioning subsystems, submitting jobs, invoking z/OS REST APIs, and executing TSO/E functions. Each definition in the repository encodes such a procedure so z/OSMF can walk an administrator through it, and the project — hosted under the Open Mainframe Project foundation — existed as the single open community venue for sharing and improving these definitions, spanning IBM GTS workflows, provisioning examples, and z/OSMF samples. Nothing in the repository involves AI, model calls, or agentic tool execution; its presence in a coding-agent census stems from a misclassification at collection time rather than any hidden agent capability. The project has formally ended: the README carries an Emeritus notice stating it is no longer maintained, with last activity in mid-2024. Its practical remainder is a browsable archive of mainframe workflow examples for z/OSMF users, documented in the IBM z/OSMF knowledge center, and its license is Apache-2.0.
