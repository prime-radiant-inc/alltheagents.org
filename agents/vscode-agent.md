Built-in agent-first experience in VS Code with dedicated Agents window, multiple chat surfaces (Agents window, Chat view, inline chat, Quick Chat). Full MCP support, plugin system, subagents, hooks, and plan mode. Agents can autonomously analyze code, make changes, run terminal commands, and use tools. Backed by GitHub Copilot's multi-model provider system.
