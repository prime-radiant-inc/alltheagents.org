An 'IDE for AI CLI agents.' Unifies the AI-coding workflow into a single five-stage pipeline — Docs -> Plan -> Terminal -> Autonomous Tasks -> Version Control — where each stage inherits the context of the previous one. Runs multiple AI CLIs (Claude Code, Antigravity, Codex) in parallel, each in its own isolated git worktree, with scheduling around rate limits, multi-agent debate (architect/developer/reviewer), and a built-in Git client + review queue to land the diffs.
