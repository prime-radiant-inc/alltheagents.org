Palomino is a Mac workspace for developers who run more than one coding agent at a time: it puts Claude Code, Codex, Pi, and fx side by side in one window, each next to the terminals, browsers, and file views it needs, with tabs and panes for parallel work and GPU-rendered scrolling the site benchmarks against terminal emulators. The agents are the ones you already have installed — Palomino is a container for their sessions, not an agent or a model gateway itself — and the free download serves a real Apple disk image (18.9 MB) with unlimited workspaces, agents, and panes and no account required. The Product Hunt badge and the site's film frame it as speed-first: native Rust for the shell of the experience, rendered on the GPU, with the agent panes showing live transcripts and diffs as they work. It is built by Appstudio26 LLC (an Illinois company), ships for macOS today with a Windows waitlist and Linux listed without a download, and its users are developers who want their agents' work visible in one place instead of scattered across terminal windows and editor tabs.
