Intentionally compact implementation of a Claude Code-like agent loop suitable for study, modification, and as a reference architecture. Available in 5 languages. Features full-screen TUI with session persistence, review-before-write edits, layered memory, context auto-compact/collapse, oversized-result offloading to disk, and local skills via SKILL.md files.
