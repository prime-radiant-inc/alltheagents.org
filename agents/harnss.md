Unified desktop interface for multiple AI coding agents built on the Agent Client Protocol (ACP), enabling simultaneous side-by-side agent sessions without context loss. Rich tool visualization transforms raw JSON into interactive cards with word-level diffs; all-in-one workspace with terminal, browser, git, MCP, and file panels scoped per project.
