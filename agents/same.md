Same targets builders who want a working web application from a description, then the ability to keep steering it in natural language without losing the escape hatch of editing code directly. Prompted changes run against a versioned project so any step can be reverted, and deployments push to the web with managed integrations for source control, databases, and authentication. Documentation at docs.same.new covers the prompting model, manual editing, project management, and troubleshooting, with an llms.txt index for machine consumption. The service is freemium: building is free to start, with paid subscriptions gated by token-based usage. Its audience is the large non-expert builder population — the product claims over 600,000 users — iterating from prompt to deployed app.
