Native desktop (Electron) shell around the pi coding agent runtime with a Codex-style threaded timeline UI, git worktrees per thread, multi-agent orchestration (supervisor/worker), integrated PTY terminal, and inline diff viewer. Uses pi's JSONL session files as the source of truth via a thin pi-sdk-driver adapter.
