Codebuff, now distributed as Freebuff, replaces the single-model coding assistant with a team of specialized agents: context agents find relevant files, implementation agents edit code, review agents verify changes, and research agents gather external information, with the desktop product running parallel agents in isolated workspaces. The service is funded by text ads rather than subscriptions or API keys, which makes it free but means prompts and code may be used for ad personalization and, where disclosed, model training; region-limited users get a reduced model set and session caps. Five products share the same engine: a terminal CLI, a desktop app for parallel local agents, a web app builder, cloud agents that work GitHub repos directly, and a research chat. Desktop can additionally drive locally installed Claude Code and Codex agents under the user's own provider accounts.
