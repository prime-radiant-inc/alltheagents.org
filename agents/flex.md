Research codebase implementing Forward Learning from Experience, where agents improve via an evolvable experience library rather than modifying model parameters. Evaluated on AIME25 (math), USPTO-50k (chemical retrosynthesis), and ProteinGym (protein fitness). Not a software-engineering coding agent harness; it's a scientific reasoning agent research framework.
