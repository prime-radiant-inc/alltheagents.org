First open environment for training and verifying real-world software engineering agents. Contains 2.4K real tasks from 11 Python repositories with pre-built Docker images. Achieved a new open state-of-the-art (32% on SWE-Bench Verified, 26% on SWE-Bench Lite). ICML 2025 accepted. Combines repository context, executable environments, and test verification.
