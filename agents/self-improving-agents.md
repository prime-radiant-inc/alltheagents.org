Research presenting 4 progressive levels of self-improving code agents; the Arena Loop (L4) uses adversarial co-evolution where code agents and test agents compete, demonstrating that agents scoring 90-100% on original tests dropped to 62-66% under adversarial suites. L3 agents rewrite their own source code with crash-recovery validation.
