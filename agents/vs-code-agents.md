Multi-agent workflow system for GitHub Copilot in VS Code bringing structure, quality gates, and long-term memory to AI-assisted development. Specialized agents (Planner, Implementer, Security, QA, etc.) each own a specific part of the dev workflow with clear constraints and document-driven output; designed for persistent, workspace-scoped memory via Flowbaby.
