Orchestration layer that sits on top of coding agents (Claude Code, OpenAI Codex) to automate the full software development lifecycle using a pipeline of 69 specialist agents (architect, senior-dev, code-reviewer, QA, security, devops, etc.). User intervenes only at two approval gates: design and deploy. Ships as a Claude Code plugin (.claude-plugin), includes an mcp-servers directory, 60 known product archetypes across 15 industries, 6 reusable pipelines, per-agent cost tracking, DORA metrics, and a local board UI at localhost:3141.
