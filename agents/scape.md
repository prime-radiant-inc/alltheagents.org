Scape is built for the desk where four terminals each run a different agent and the human is the bottleneck for approvals. The macOS app runs unlimited sessions, each isolated in its own git worktree, and layers a code inspector, watchdogs that auto-field routine questions, and voice transcription on top. Argus supervises: it takes an objective, spawns child agents, auto-approves routine decisions, and escalates the rest, while Playbooks encode repeatable multi-step processes that agents execute and report into owned tables. Agent-to-agent chat and networked rendezvous let a Claude session debate a Codex one, including across teammates' machines over encrypted channels. It requires the user's existing agent subscriptions, ships as a beta macOS app from Scape Labs with a public releases repo, and targets developers running several agents daily.
