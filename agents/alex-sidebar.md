Alex Sidebar targeted iOS and macOS developers who wanted agentic assistance inside Xcode rather than a chat pane: it fixed build errors, added Swift Package Manager dependencies by navigating Xcode's UI, executed shell commands, ran the app in the Simulator, and searched the web, alongside autocomplete and image-to-code. Code never transited its servers — BYO OpenAI-compatible endpoints, local Ollama/LM Studio models, and locally stored embeddings (VoyageAI) were the defaults, with hosted inference from Anthropic, OpenAI, Fireworks, Cerebras, or Gemini. Pricing was $30/month Pro or $200/month Unlimited with a 7-day trial. The banner 'We've joined OpenAI' ended the standalone product; downloads stopped October 1 and remaining links point at final GitHub releases.
