Vendor-neutral, model-agnostic security coding agent skills framework from the Coalition for Secure AI (CoSAI, an OASIS Open Project). Ships unified security rules in markdown covering cryptography, input validation, authentication, authorization, supply chain, cloud security, and post-quantum cryptography; includes translators for popular coding agents, an MCP server for centralized organizational deployment, and validators to test compliance.
