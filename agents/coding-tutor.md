Research project (ACL 2025 Findings paper) proposing Trace-and-Verify (Traver), an agent workflow combining knowledge tracing and turn-by-turn verification for LLM task-tutoring agents using coding tutoring as a scenario; introduces DICT (Dialogue for Coding Tutoring), a novel evaluation protocol combining student simulation and coding tests. Not a production coding agent harness.
