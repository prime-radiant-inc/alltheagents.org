Self-hosted code intelligence platform that helps humans and agents understand codebases. Combines AI-powered Q&A with inline citations, code search (regex/filters/boolean across all repos/branches on any code host), IDE-level cross-repo goto definition and find references, and a built-in file explorer. Enables both humans and AI agents to navigate large multi-repo codebases. Public demo at app.sourcebot.dev.
