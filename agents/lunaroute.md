High-performance local proxy for AI coding assistants (Claude Code, OpenAI Codex CLI, OpenCode) with zero-overhead passthrough, sub-millisecond latency, dual-dialect passthrough (OpenAI + Anthropic formats simultaneously), comprehensive session recording (SQLite + JSONL), automatic PII redaction, built-in Web UI, and Prometheus metrics. One-command setup via eval $(lunaroute-server env).
