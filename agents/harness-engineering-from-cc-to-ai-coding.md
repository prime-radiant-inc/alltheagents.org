Chinese technical book ('Harness Engineering: From Claude Code Source Code to AI Coding Best Practices', nicknamed 'the horse book') that reverse-engineers Claude Code v2.1.88 via source maps to extract architecture patterns, context strategies, permission systems, and production practices for AI coding agents. Covers agent loop architecture, tool execution orchestration, auto/micro-compression, token budgets, prompt cache, permission modes, YOLO classifier, hooks, skill systems, feature flags, and unpublished capability pipelines - translating them into reusable patterns. English translation in progress.
