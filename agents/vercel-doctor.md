Reduces Vercel bills with one command. Scans Next.js codebases for patterns that inflate Vercel bills (long function duration, uncached routes, unoptimized images) and detects dead code, outputting actionable diagnostics. Supports coding agent skills for Cursor, Claude Code, Amp Code, Codex, Gemini CLI, OpenCode, Windsurf, and Antigravity. Generates AI-ready fix prompts for popular coding agents. Supports Next.js 15/16+.
