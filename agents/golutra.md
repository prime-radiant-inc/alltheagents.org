Multi-agent AI orchestration workspace (Tauri desktop app) that unifies existing CLI coding tools into a parallel AI workforce. CLI-native approach — no migration, keeps existing CLI tools while adding multi-agent orchestration. Visual + terminal hybrid (Stealth Terminal with direct prompt injection into terminal streams), unlimited parallel multi-agent execution with automated result handoff, one-click template import/export, real-time monitoring. MCP via golutra-mcp, memory via EverOS. BSL-1.1 licensed (free for commercial software development). Early stage but actively developed.
